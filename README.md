## About Me

I'm a **Technical Support Team Leader** and **Laravel developer** who keeps multi-branch medical and business infrastructure running, and builds the web systems that sit on top of it.

| | |
|---|---|
| **IT Operations** | Multi-branch networks, wireless point-to-point links (NanoStation / PowerBeam), core servers (Print, Millensys PACS, Veeam, Databases) |
| **Medical IT** | Radiology environments: MRI, CT, X-Ray, PACS / RIS / DICOM |
| **Web Development** | Laravel, PHP, MySQL, Tailwind CSS, Blade |
| **Automation** | Workflows and integrations with n8n, Supabase and APIs |
| **Education** | B.Sc. Information Technology (Software), Beni Suef Technological University |
| **Community** | Egypt Digital Pioneers Initiative (DEPI), NASA Space Apps Cairo |
| **Certifications** | CCNA, MCSA |
